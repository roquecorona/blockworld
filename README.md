# Blockworld

A blocky building and survival game that runs in the browser on phones, tablets and computers.
Worlds and players are saved on each device. Use Back Up / Move to copy a world to another device.

Play: https://roquecorona.github.io/blockworld/

On a phone, open the link and choose "Add to Home Screen" to install it like an app.

Works offline: open it once with internet (or install it to the home screen) and it keeps working without a connection.

Includes three.js r128 (MIT licence) and the fonts Press Start 2P and VT323 (SIL Open Font License).
